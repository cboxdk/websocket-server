# Cookbook

Practical, task-focused recipes for common operations.

- **[Seed apps from env](seed-apps-from-env.md)** — provision apps
  declaratively at boot with `REVERB_SEED_APPS`, idempotently.
- **[Client integration](client-integration.md)** — connect a Pusher-compatible
  client with `laravel-echo` and `pusher-js`.
- **[Scaling](scaling.md)** — run multiple instances with Redis-backed scaling
  and scrape metrics across the cluster.
