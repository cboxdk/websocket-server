# Getting started

Cbox WebSocket Server ships as a Docker image and as a standard Laravel project
you can run locally. This section covers both.

- **[Installation](installation.md)** — run the server with Docker, Docker
  Compose, or locally with `composer setup` / `composer dev`, and generate the
  required `APP_KEY`.

If you just want the fastest path to a working connection, read the
[Quickstart](../quickstart.md) first, then come back here for the deployment
detail.
